The same files are attached to the [latest release](../../releases/latest) and listed on the download page, https://skuirrels.github.io/mapster-releases/

- **Windows:** the Setup .exe is recommended; the .msi suits managed installs. If SmartScreen warns, choose **More info → Run anyway**.
- **macOS:** Apple Silicon is for M1 and later Macs, Intel for older ones. Open the .dmg and drag Mapster to Applications. The first time, right-click Mapster and choose **Open** (the builds aren't notarized yet).
- **Linux:** the AppImage runs on any distribution; use the .deb on Debian/Ubuntu and the .rpm on Fedora/openSUSE.

Installed copies update themselves: Mapster checks for a newer version when it starts, and Help ▸ Check for Updates checks on demand.
